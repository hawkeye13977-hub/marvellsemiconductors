What is a Multiplexer?

A Multiplexer (MUX) is a digital circuit that selects one of several input signals and forwards it to a single output.

A 2:1 Multiplexer has two data inputs (A and B), one select line (SEL), and one output (Y). Depending on the value of the select signal:

  • SEL = 0 → Output = A
  • SEL = 1 → Output = B

Multiplexers are widely used in CPUs, memory systems, communication hardware, and System-on-Chip (SoC) designs for selecting one signal from multiple sources.

Multiplexer & Demultiplexer

Figure 1: Comparison of a 2:1 Multiplexer and a 1:2 Demultiplexer. A Multiplexer selects one of many inputs, while a Demultiplexer routes one input to one of many outputs.

Truth Table

The output depends on the value of the select signal (SEL).

SEL Output (Y) Description
0 A Output follows Input A
1 B Output follows Input B

Boolean Equation

The Boolean equation for a 2:1 Multiplexer is: 


Y = (~SEL & A) | (SEL & B)

This equation means:

  • SEL = 0 → Output = A
  • SEL = 1 → Output = B

Verilog Design Code 

module mux2to1(

input a,
input b,
input sel,

output y

);

assign y = sel ? b : a;

endmodule

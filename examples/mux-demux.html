Introduction

Multiplexers and Demultiplexers are fundamental combinational circuits used in digital systems for selecting and routing data efficiently.

A Multiplexer (MUX) selects one input from multiple inputs and forwards it to a single output. A Demultiplexer (DEMUX) performs the opposite function by routing a single input to one of multiple outputs.

These circuits are widely used in processors, memory controllers, communication systems, FPGAs, and ASIC designs.

2:1 Multiplexer (MUX)

A data selector that forwards one of two inputs to a single output.

A 2:1 Multiplexer (MUX) has two data inputs (A and B), one select line (SEL), and one output (Y).

The select line determines which input is connected to the output.

  • SEL = 0 → Output = A
  • SEL = 1 → Output = B

Multiplexers are widely used in CPUs, memory controllers, ALUs, communication systems, and System-on-Chip (SoC) designs.

MUX Truth Table

SEL Output (Y)
0 A
1 B

Boolean Equation

The output equation for a 2:1 Multiplexer is: 


Y = (~SEL & A) | (SEL & B)

This equation means:

  • SEL = 0 → Output = A
  • SEL = 1 → Output = B

Verilog Design Code – 2:1 Multiplexer 

module mux2to1 (

input a,
input b,
input sel,

output y

);

assign y = sel ? b : a;

endmodule

1:2 Demultiplexer (DEMUX)

A data distributor that routes one input to one of two outputs.

A 1:2 Demultiplexer (DEMUX) has one data input (IN), one select line (SEL), and two outputs (Y0 and Y1).

The select line determines which output receives the input signal.

  • SEL = 0 → Input is routed to Y0
  • SEL = 1 → Input is routed to Y1

Demultiplexers are widely used in communication systems, memory address decoding, data routing, and digital control applications.

DEMUX Truth Table

IN SEL Y0 Y1
1 0 1 0
1 1 0 1

Boolean Equations 


Y0 = IN & ~SEL

Y1 = IN & SEL

Verilog Design Code – 1:2 Demultiplexer 

module demux1to2(

input in,
input sel,

output y0,
output y1

);

assign y0 = ~sel & in;
assign y1 =  sel & in;

endmodule

💡 Industry Tip

Multiplexers and Demultiplexers are among the most commonly used combinational circuits in modern digital systems.

  • Multiplexers are widely used in CPUs, ALUs, memory controllers, and bus architectures for selecting one signal from multiple inputs.
  • Demultiplexers are commonly used for address decoding, data distribution, communication interfaces, and memory selection.
  • RTL Design and Verification Engineers frequently encounter MUX and DEMUX logic in ASIC and FPGA projects.

Key Takeaways

  • Multiplexers select one input from multiple inputs.
  • Demultiplexers route one input to one of multiple outputs.
  • MUX is commonly called a Data Selector.
  • DEMUX is commonly called a Data Distributor.
  • Both are essential combinational circuits used in CPUs, SoCs, ASICs, and FPGA designs.
  • Verilog provides a simple and efficient way to implement both circuits.

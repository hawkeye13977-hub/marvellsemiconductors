What is Combinational Logic?

Digital circuits whose outputs depend only on their current inputs.

Combinational logic is a type of digital logic in which the output depends only on the present values of the inputs. Unlike sequential logic, combinational circuits do not store previous input values or depend on past states.

Whenever an input changes, the circuit produces the corresponding output after the propagation delay of the logic.

Common examples of combinational circuits include:

  • Logic gates
  • Multiplexers
  • Demultiplexers
  • Encoders
  • Decoders
  • Comparators
  • Adders and subtractors

Combinational logic is one of the most important foundations of RTL Design because many hardware functions are implemented using these circuits.

Combinational vs Sequential Logic

Understanding the key difference between the two major types of digital logic.

Combinational Logic

  • Output depends only on current inputs.
  • Does not store previous values.
  • Does not require a clock.
  • Examples: MUX, Decoder, Encoder and Adder.

Sequential Logic

  • Output depends on current inputs and previous state.
  • Contains memory elements.
  • Usually operates with a clock.
  • Examples: Flip-Flops, Registers and Counters.
Feature Combinational Sequential
Depends on Current inputs Current inputs + previous state
Memory No Yes
Clock Not required Typically required
Examples MUX, Decoder, Adder Flip-Flop, Register, Counter

From inputs to logic equations and finally to the output.

1. Inputs

The circuit receives one or more binary input signals.

2. Logic

Logic gates or Boolean equations process the input signals.

3. Output

The circuit produces an output based on the current inputs.

Inputs → Logic Function → Output

Continuous Assignment in Verilog

Using the assign statement to describe combinational logic.

In Verilog, combinational logic can be described using a continuous assignment statement. The assign keyword continuously drives a value onto a net based on an expression.

Whenever a signal used in the expression changes, the output is automatically updated.

Basic Syntax 

assign output_signal = expression;

Example 

module and_gate(

input a,
input b,

output y

);

assign y = a & b;

endmodule

Here, the output y continuously follows the Boolean expression A AND B.

  • a and b are the inputs.
  • & represents the AND operation.
  • y is continuously driven by the expression.

2-Input AND Gate

Verilog Design 

module and_gate(

input a,
input b,

output y

);

assign y = a & b;

endmodule

The assign statement continuously evaluates the expression a & b and drives the result to output y.

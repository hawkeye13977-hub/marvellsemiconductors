What is Combinational Logic?

Digital circuits whose outputs depend only on their current inputs.

Combinational logic is a type of digital logic in which the output depends only on the present values of the inputs. Unlike sequential logic, combinational circuits do not store previous input values or depend on past states.

Whenever an input changes, the circuit produces the corresponding output after the propagation delay of the logic.

Common examples of combinational circuits include:

  • Logic gates
  • Multiplexers
  • Demultiplexers
  • Encoders
  • Decoders
  • Comparators
  • Adders and subtractors

Combinational logic is one of the most important foundations of RTL Design because many hardware functions are implemented using these circuits.

Combinational vs Sequential Logic

Understanding the key difference between the two major types of digital logic.

Combinational Logic

  • Output depends only on current inputs.
  • Does not store previous values.
  • Does not require a clock.
  • Examples: MUX, Decoder, Encoder and Adder.

Sequential Logic

  • Output depends on current inputs and previous state.
  • Contains memory elements.
  • Usually operates with a clock.
  • Examples: Flip-Flops, Registers and Counters.
Feature Combinational Sequential
Depends on Current inputs Current inputs + previous state
Memory No Yes
Clock Not required Typically required
Examples MUX, Decoder, Adder Flip-Flop, Register, Counter

Continuous Assignment in Verilog

Using the assign statement to describe combinational logic.

In Verilog, combinational logic can be described using a continuous assignment statement. The assign keyword continuously drives a value onto a net based on an expression.

Whenever a signal used in the expression changes, the output is automatically updated.

Basic Syntax 

assign output_signal = expression;

Example 

module and_gate(

input a,
input b,

output y

);

assign y = a & b;

endmodule

Here, the output y continuously follows the Boolean expression A AND B.

  • a and b are the inputs.
  • & represents the AND operation.
  • y is continuously driven by the expression.

2:1 Multiplexer

A multiplexer selects one of two inputs and sends it to a single output.

How a 2:1 MUX Works

A 2:1 multiplexer has two data inputs, A and B, one select signal SEL, and one output Y. The select signal determines which input appears at the output.

SEL Output Y
0 A
1 B

Boolean Equation 

Y = (~SEL & A) | (SEL & B)

Verilog Design 

module mux2to1(

input a,
input b,
input sel,

output y

);

assign y = sel ? b : a;

endmodule

The conditional operator ? selects between A and B based on the value of SEL. When SEL = 0, the output follows A. When SEL = 1, the output follows B.

Combinational Logic Using always @(*)

Another common way to describe combinational logic in Verilog.

Combinational logic can also be described using an always @(*) block. The block executes whenever any signal used inside the block changes.

Example 

module and_gate(

input a,
input b,

output reg y

);

always @(*) begin

    y = a & b;

end

endmodule

Why use always @(*)?

  • Useful for describing more complex combinational logic.
  • Allows multiple statements inside one combinational block.
  • The * automatically includes signals used by the block in its sensitivity list.

Important RTL Rule

When describing combinational logic using always @(*), make sure every output is assigned for all possible conditions. Otherwise, unintended latches can be inferred.

assign vs always @(*)

Two common ways to describe combinational logic in Verilog.

Feature assign always @(*)
Type Continuous assignment Procedural block
Best suited for Simple logic equations More complex combinational logic
Example assign y = a & b; always @(*)
Output type Typically wire Typically reg in Verilog

RTL Design Tip

For simple Boolean relationships, assign is often the clearest choice. For combinational logic containing multiple conditions or statements, always @(*) can make the RTL easier to organize.
